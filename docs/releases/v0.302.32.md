# Codegraff v0.302.32

Replies no longer repeat, and Anthropic Console sign-in works on servers.

## A handoff shows once

When the agent hands the turn back with `yield_turn`, ACP clients such as the
desktop app showed its closing message twice, and the handoff's tool row kept
spinning. The message now arrives once and the row completes.

## Anthropic Console sign-in away from a browser

`graff login anthropic` runs Anthropic's `ant auth login`, which by default
waits for a browser callback on the machine graff runs on. When the desktop app
signs in a server, or you are on SSH or a machine without a display, that
callback never arrives, so the sign-in waited forever and no Claude models were
offered. graff now asks for Anthropic's code flow there: the page shows a code,
and the desktop app (or you) pastes it back. You still need Anthropic's `ant`
CLI installed on that machine.

## ACP

- After `/resume` or `--branch`, the prompt result reports the conversation the
  session moved onto, so a client restoring after a restart opens the right one
  instead of failing with "Unknown session ID".
- `graff acp login` signs in. Clients that run the advertised `login` argument
  after `acp` started the ACP server instead.
- T3 Code gets a client profile: slash commands as the first prompt block, its
  working folder kept as given, and a model picker of reachable models.

## Also

- `graff tui` finds a client installed by the desktop app, and with none
  installed offers to download one, checked against its published checksum.
- The Linux MCP service unit is valid again: systemd rejected its quoted
  working directory.
- When something stops graff with SIGTERM, graff writes which process sent it
  to stderr before exiting.
