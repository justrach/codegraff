# Codegraff v0.302.34

Gemini API key sign-in works again, and a gateway timeout no longer ends the turn.

## Gemini API key sign-in

Google's Interactions endpoint now reads a history entry shaped like a chat
message as the older turn format it no longer accepts, and rejects the request:

```
api error: When using the steps-based API version, use step_list input format instead of turn_list.
```

graff built the prompt that way, so every request with a Gemini API key failed
on its first message. The prompt, image prompts, resumed sessions and compaction
summaries now go out as Interactions steps.

Current Gemini models also reject a `minimal` thinking level, so `/effort
minimal` and `none` now run as `low`. Gemini 4 Argon is listed with its 1M
context, its effort levels and its price, so the usage footer shows what a
session cost.

## Gateway timeouts are retried

When the hosted gateway gives up on a stalled upstream, it ends the stream with
a `gateway_timeout` error that says to retry. graff treated that as final and
ended the turn. It now retries it like any other transient server error.
