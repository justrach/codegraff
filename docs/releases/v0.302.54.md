# v0.302.54

Quieter terminal startup, clearer live-thinking controls, and smaller bundled runtime text.

- Normal terminal startup keeps background connection receipts and listener diagnostics behind `GRAFF_REPL_DEBUG=1`; timing remains behind `GRAFF_BOOT_DEBUG=1`. Explicit inspection commands and listener ownership protections remain available.
- Live thinking shows `Ctrl+T collapse` and `Ctrl+T expand` beside its header. Enable thinking with `/thinking on`; completed scrollback remains read-only.
- Command-line help, release history, and bundled playbooks are compressed until requested. Existing content is preserved.
- Long home paths no longer prevent installation of the macOS background-launch shim.

The build settings are unchanged: graff's application code uses ReleaseSafe; the standard library and thin entry wrapper use ReleaseSmall.

Includes all changes from v0.302.53.
