# v0.0.252 (2026-08-13)

xAI joins the live-catalog club, the peer-channel spacing fix grows teeth,
and the release workflow learns to survive a pre-existing release.

- **Grok models are discovered live.** The xAI provider spec was the last
  major catalog still baked into the binary — new Grok rollouts needed a
  release to become routable. xAI is now enrolled in the generic live
  discovery every other router already used: an authenticated
  `https://api.x.ai/v1/models` fetch, cached for 6h at
  `~/.codegraff/xai-models.json` (stale cache is the offline fallback), and
  demand-gated so nothing hits the network without an xAI credential. Live
  rows replace the provider slice 1:1; context windows the endpoint omits
  inherit from the baked table (a `grok-4.3-fast` rollout inherits at the
  `-` boundary), and unknown families take the conservative default. This
  mirrors how grok-build itself resolves its catalog — backend-first,
  etag-cached, bundled fallback — so Grok parity no longer waits on us.
- **The #469 peer-message bracket is pinned as an event sequence.** The
  v0.0.251 spacing fix extracted its emission into one helper
  (`renderPeerBlock`: blank, markers, lines, blank — silence for a
  history-only drain) with a unit test on the captured sink events, because
  a PTY transcript provably cannot attribute a blank line to the drain
  (neighbors emit their own). A new CI-wired PTY smoke test covers what the
  unit test can't: a device-room broadcast planted at the prompt renders as
  a peer line next turn.
- **The release workflow survives a release that already exists.**
  `release.yml` now uploads assets onto an existing tag's release
  (`gh release upload --clobber`) with an expected-asset assertion, instead
  of failing into an untagged draft — the race that briefly left v0.0.251
  asset-less and broke `graff update` with a 404.
