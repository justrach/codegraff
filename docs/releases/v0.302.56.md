# v0.302.56

Dependency symlinks now work with native file tools without allowing paths to escape their selected tool root.

- Reads, directory listings, edits, and writes accept links whose resolved targets remain within the permitted root.
- Escaping, dangling, and cyclic links remain blocked, including links at the final path component.
- Ordinary missing paths remain available for new writes. Explicitly allowed extra roots retain their own boundaries.
- The path check is a preflight guard, not an atomic sandbox against concurrent filesystem replacement.

Includes all changes from v0.302.55. Build optimization and runtime-safety settings are unchanged.
