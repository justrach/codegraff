# Codegraff v0.302.38

Faster starts on Windows, and the code-intelligence companion is found there.

## Finding programs on PATH

graff looks programs up on PATH, for example its code-intelligence companion
before `graff acp` answers its first request. The lookup split PATH on `:`. On
Windows the delimiter is `;` and every entry holds a drive colon, so it probed
fragments of entries instead. A fragment that reads as a network path can take
seconds to fail, and that delay came before the first answer on every start.
The lookup also asked for the bare name, never the `.exe`, so the companion was
never found on Windows at all.

Lookups now split on the platform's delimiter and, on Windows, try `.exe`,
`.cmd`, `.bat` and `.com`. On a Windows test runner the slowest first answer
went from 3.3 s to 1.0 s.
