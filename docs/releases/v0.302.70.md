# v0.302.70

Fixes for Claude Agent tool-list refreshes, empty-reply failures, simulator tests and the clipboard, large uploads, and peer mail to resumed ACP chats.

- **Claude Agent: a reply that starts during a tool-list refresh arrives whole.** After the model loads a tool, graff tells Claude Code its tool list changed and waits for it to read the new list. Anything else Claude Code sent during that wait was dropped, so a reply that was already streaming lost its start and the turn failed with "unparseable response". Those lines are now kept and read in order. (#1804)
- **An empty-reply failure explains itself.** When the provider returns an empty reply 6 times in a row, the turn ends with a message saying so: the conversation is kept, and sending again retries. ACP clients used to show only `EmptyCompletion`. (#1802)
- **Simulator tests can't overwrite your clipboard.** With the Simulator app open and Edit > Automatically Sync Pasteboard on (the default), a simulator test that copies text replaced the Mac's clipboard, and nothing restored it. A command that runs simulator tests (`xcodebuild test`, `test-without-building`, `xctest`) or writes a simulator pasteboard (`simctl pbcopy`, `pbsync`) is now refused while that is the case, with steps to fix it: quit the Simulator app or turn the menu item off. graff never changes the setting and never reads or restores the clipboard. `GRAFF_ALLOW_SIM_PASTEBOARD=1` turns the check off. (#1801)
- **Large uploads aren't cut off while they're still sending.** Connecting, uploading the request and waiting for the response each have their own limit. The upload limit grows with the body and resets while bytes keep moving (a 1 MiB body gets up to 94 s), so a slow but live upload completes. A server that stops reading still fails, and Esc still cancels. (#1785)
- **Peer mail reaches resumed ACP chats.** A chat loaded or forked over ACP kept its old peer name, so mail sent to its session id found no one. It now registers under its own session id, which lets Harness deliver chat-to-chat messages through the peer inbox. (#1803)

Includes all changes from v0.302.69.
