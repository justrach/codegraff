# v0.302.74

- Rejected encrypted compaction state can recover from a private checkpoint containing the exact input and all later conversation. New server compactions retain that checkpoint before replacing history. Missing, changed or invalid checkpoints leave history unchanged and report the blocked state (#1822).
- Short TLS-construction outages have a longer bounded recovery window, without changing ordinary retry limits, cancellation or certificate verification (#1826).

Existing encrypted state created before this release cannot be reconstructed automatically unless an exact checkpoint is available. Detailed diagnostics and conversation contents remain local.
