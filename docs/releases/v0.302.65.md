# v0.302.65

Claude Agent gets its full 1M context window.

- **1M, not 200k.** Claude Code runs the current Claude models at a 1M window natively, but graff listed every Claude Agent model at 200k. graff compacted the conversation at a fifth of the window, and clients showed "200k context". The Claude Agent models now carry 1M, the same as the Anthropic provider's.
- **`[1m]` names.** A model id with Claude Code's `[1m]` suffix (for example `claude-agent/claude-sonnet-5-5[1m]`) resolves to 1M instead of the 200k default for unknown models. (#1783)

Includes all changes from v0.302.64.
