# v0.302.57

Reliability fixes for images, failed requests, streamed errors, and long-running sessions.

- **Images are typed by their bytes.** `read_image`, `/image`, paste, ACP and MCP image blocks, and JSON image input detect PNG, JPEG, GIF, and WebP from the file's contents. A WebP saved as `.png` is sent as WebP. A file that is none of these is refused before it is queued, so a mislabelled screenshot can no longer leave a block in the transcript that fails every later turn (#1762).
- **Retrying after a failed request works.** A turn that fails before any reply now ends with a `[request failed: …]` marker in history, saved with the session. Resending the same prompt makes a new request; a genuine duplicate submission of a pending prompt is still skipped (#1729).
- **Streamed error events surface as errors.** An SSE body holding only an error event is reported with the provider's error type and message on chat-completions, Anthropic Messages, OpenAI Responses, and Gemini Interactions, instead of failing reassembly and being retried as a truncated response. Invalid-request errors are not retried; overload and server errors keep their bounded retry (#748).
- **Withdrawn checklist items can be closed.** `todo_write` accepts `cancelled` with a required `reason` for work the user withdrew or delegated. The item stays visible as `[-] item (cancelled: reason)`, is never counted as verified, and no longer blocks completion. A verification item can be cancelled after a newer user message or an `ask_user` answer (#1520).
- **Workspace switches reach ACP clients immediately.** `session_info_update` is sent right after the `workspace` tool moves the session, and carries the session's absolute folder as `_meta["graff/cwd"]` (#1737).
- **Retained workers survive a workspace switch.** `subagent_resume` finds a retained worker's checkpoint under the folder it was saved in, and refusals explain whether the id is malformed, the checkpoint is missing, or the worker is still running (#1724).
- **Polling a running subagent is not a repeat.** The identical-tool-call guard skips `agent_output` snapshots that report a subagent still running (#1706).

Includes all changes from v0.302.56.
