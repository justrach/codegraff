# Codegraff v0.302.30

MCP servers that say what's wrong and reconnect on request, sign-in with an
Anthropic Console account, and Claude Haiku 5.5.

Releases are now tagged with three parts (`v0.302.N`). `graff update` treats
this release as newer than every `v0.0.302.N`.

## MCP servers report their state and reconnect

When an MCP server didn't work, graff used to fold it into "not connected —
/mcp trust" and offer nothing but a new session. Now every configured server
has one status row: ready, starts on first use, failed (with the server's own
error), needs sign-in, off, or optional.

- `graff mcp status [--json]` reads the rows from config and cache without
  starting anything. `/mcp` shows the same rows inside a session.
- `graff mcp reconnect <name>|--all` and `/mcp reconnect <name>` run a fresh
  handshake and refresh the server's cached tool list. A failed reconnect
  shows the server's last stderr line.
- `graff mcp enable|disable <name>` switch a server on or off without
  editing its config.

Three bugs behind "it works after a reconnect" are fixed:

- Servers that share a launcher command and differ only in `cwd` no longer
  advertise each other's tools.
- A server's `env` now adds to graff's environment instead of replacing it,
  so `npx` servers with an env var start.
- Entries marked `"enabled": false` are no longer started.

## Sign in with an Anthropic Console account

`graff login anthropic` runs Anthropic's `ant auth login`. graff then reads
the profile it writes, sends it as a Bearer token, and refreshes it through
`ant`, so requests bill to that Console account's API credits. An
`ANTHROPIC_API_KEY` still takes precedence.

## Claude Haiku 5.5

Claude Haiku 5.5 replaces Claude Haiku 4.5 in the catalog. It has a 1M-token
context window, long-context pricing above 100k prompt tokens, and adaptive
thinking with effort levels.
