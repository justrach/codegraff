# Codegraff v0.302.31

Tool rows that never finished, and `graff update` on Windows.

## Every tool row finishes

Some tools end without a result on graff's event stream: `peer_message`,
`load_tool_schemas` and `todo_write` only send a finish event. graff's ACP
output ignored that event, so clients such as the desktop app showed those
tools as running forever. Each of them now gets its completed or failed
status. Ordinary tools still end once, on their result.

## `graff update` on Windows

`graff update` ran the shell installer through `/bin/sh`, which Windows does
not have, so it failed with "could not launch installer". On Windows it now
runs the release's `install.ps1` into the folder graff is installed in. The
installer checks the download against the release's SHA256SUMS and replaces
the running `graff.exe`.

If you are on Windows with an older graff, update once by running the
installer again:

    irm https://github.com/justrach/codegraff/releases/latest/download/install.ps1 | iex

`graff update` works from then on.
