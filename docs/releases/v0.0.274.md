# v0.0.274 (2026-08-23)

Rate-limit retries stop dumping the provider's error envelope onto the REPL.

A 429 used to print the full captured body next to the retry line, which
leaked vendor JSON: account `user_id`s, BYOK/settings URLs, and routing
docs. The retry line is now just:

    [rate limited (429) — retrying in 1s (1/5)]

Give-up is the same — `[request failed: RateLimited — giving up this turn]`
with no body. The captured snippet is still used internally so a billing
quota 429 fails fast instead of retrying.
