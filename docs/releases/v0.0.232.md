# Verified image generation + honest clipboard pastes

v0.0.232 adds an `imagegen` tool that proves every image it reports, and makes
clipboard paste failures honest — and usually recoverable — instead of silent.

## imagegen: image generation the model can't fake (#352, PR #355)

- A new codex-gated `imagegen` tool generates images through your Codex
  ChatGPT plan (hosted `image_gen`, no API key) with the skill's
  `image_gen.py` CLI as an `OPENAI_API_KEY` fallback. The Codex imagegen
  skill is mirrored into `~/.harness/skills/imagegen` so `skill imagegen`
  works, LICENSE intact, with a graff addendum explaining the mapping.
- Investigating #352 caught Codex 0.141.0 *fabricating* generation success
  from a stale file, so verification is the tool's core: graff scans a
  per-run private `CODEX_HOME`, requires a fresh artifact (mtime, magic
  bytes, size floor), copies and resizes it itself, and re-verifies the
  delivered bytes. Exit 0 plus a confident transcript and no fresh artifact
  is a hard error. Concurrent generations cannot cross-attribute — spawn one
  subagent per image and they parallelize safely.
- `imagegen` respects plan mode and `--no-local-tools`, and overwrites are
  `/rewind`-snapshotted like `write_file`.
- MCP tool schemas with top-level `oneOf`/`allOf`/`anyOf` are now lowered
  instead of rewritten `oneOf`→`anyOf` — one connected MCP server can no
  longer 400 every Anthropic turn.

## Clipboard pastes stop lying (#349, #350, PR #353)

- An oversized clipboard image is downscaled to a provider-safe payload and
  attached instead of being dropped with "couldn't read the clipboard image"
  while the prompt goes out text-only. If it truly cannot fit, the error
  names the real size and the limit.
- Telegram-style file-URL clipboards and PDF clipboards now attach: capture
  cascades PNGf → file URL → PDF with `sips` normalization. macOS already
  synthesizes PNGf from any raster flavor; only pixel-less clipboards ever
  failed, and now they mostly don't.
- Every paste attempt leaves a `clipboard_paste` trace event (result, flavor,
  bytes, mime — never the payload), and the shared `/tmp/.harness-clip.png`
  race is gone in favor of unique per-paste temp paths.

## Agent PRs must explain why (#351, PR #354)

- The root system prompt now requires agent-authored PR descriptions to cover
  both **what changed** and **why** — problem, approach, trade-offs, rejected
  alternatives — proportional to the change, so later agents stop undoing
  deliberate decisions.
