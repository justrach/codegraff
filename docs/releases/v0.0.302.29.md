# Codegraff v0.0.302.29

A fix for v0.0.302.28's request tags.

## The version reaches the usage page

v0.0.302.28 started telling the Codegraff gateway which graff version, device
and app sent each request. Streamed requests sent the device and app but not
the version. They now send `User-Agent: graff/<version>` too, so the usage page
on codegraff.com shows the version for every request.
