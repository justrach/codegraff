# v0.0.271 (2026-08-22)

This release fixes Windows console UTF-8 so the line REPL and fullscreen TUI
render box-drawing and icons instead of CP437 mojibake. It ships on top of
0.0.270 (OpenRouter, `#606` path chmod).

## Windows UTF-8 console (#607)

PowerShell 5.1 and conhost default to CP437/1252. Graff emits UTF-8
(`┌─`, `·`, `⚙`, checkmarks). Without a code-page switch those bytes
render as `ΓòöΓöÇ`. zigzag's `graff repl` already called
`SetConsoleOutputCP(65001)` in raw mode; the default `graff` binary only
enabled VT processing.

`enableVtOutput()` now also sets the input and output code pages to UTF-8
before any styled output. The fullscreen TUI does the same on enter and
restores the prior pages on exit, and reads the real console size instead
of hard-coding 80×24.

This is a runtime console switch, not a manifest `activeCodePage`. It does
not change file encodings.
