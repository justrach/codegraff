# v0.302.74.2

nanocua observations keep readable text and refs by default, without coordinates.
This avoids fetching and returning geometry that ref-based actions do not need.

- Text, labels, values and enabled/focused/selected state remain available within the existing size limits.
- Request `include_frames: true` for coordinates. Ref-based actions still resolve current geometry when acting.
- `interactive_only` remains opt-in because filtering static text can hide answers and child labels.
- A headless synthetic utility comparison exercises the production serializer without driving the desktop.

Permissions, Space restrictions and ref refresh behavior are unchanged. This is
an observation-format improvement, not a native-latency or whole-session cost claim.
