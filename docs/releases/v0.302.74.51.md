# v0.302.74.51

This hotfix release cuts memory, startup, and session-resume overhead across REPL and ACP sessions, adds `-Dminimal` and per-subsystem build options, bounds `graff sessions` listing memory to a 64 KiB header prefix per file, and lands `codedb` symbol ranking and `--eval` contrastive trajectory reflection.

- `graff sessions` and `/resume` read only a 64 KiB prefix per `.session.json` file into a per-file scratch arena that resets each iteration instead of reading whole multi-megabyte session files into a single listing arena (#1848).
- `loadSession` and ACP `session/load` (`replayHistory` and `savedHere`) parse `.session.json` and `.transcript*.jsonl` generations in scoped `gpa`-backed scratch arenas freed on `defer`, keeping only active messages in `g_session_arena` and compact metadata strings in `init.arena` (#1858).
- `reclaimMessages` copies surviving `root.messages` once directly into a fresh `g_session_arena` before freeing the old arena instead of staging through a second copy; hosted gateway compaction (`gateway_compact.install`) and explicit `/compact` commands reclaim `g_session_arena` and persist the compacted session, and slash commands typed during a turn stay queued for `mainloop` rather than being injected as model steer prompts (#1845, #1859).
- Startup and hot-reload trajectory archive folding (`bench_priors.loadInto`, `foldObservations`, `route_policy.foldCells`, `orchestration_policy.foldArms`) parse JSON rows in a scoped scratch arena and store surviving priors in a replaceable arena freed on reload (#1845).
- Startup credential resolution scopes Keychain lookups to the remembered `saved_model` provider before falling back to an exhaustive scan, and `worktree_reap.orphans` skips spawning `git worktree` subprocesses when `.graff/worktrees` is absent (#1859).
- `zig build -Dminimal=true` and per-subsystem `comptime` flags (`-Dlearn`, `-Dserve`, `-Dacp`, `-Dextras`) compile out optional subsystems, reducing the `ReleaseSafe` core CLI + REPL binary by 27.3% to 3.15 MiB (#1849).
- `codedb` symbol search orders matches by reference count (`refs` descending) and path depth before alphabetical name order, and `--eval` attaches contrastive failure diagnostics and retires prompt variants below 30% pass rate after 3+ evaluations (#1855).
- The TypeScript (`@codegraff/sdk`, `@codegraff/sdk/remote`) and Python (`harness_sdk.py`) SDKs now include a zero-binary, edge-safe `ServerlessHarness` (`runAgentServerless`, `createAgentSession`) with `InMemoryWorkspace`, pluggable `WorkspaceOperations`, built-in coding tools (`createCodingTools`, `createReadOnlyTools`, `defineTool`), tool lifecycle hooks (`beforeToolCall`, `afterToolCall`, `transformContext`), mid-turn `steer` / `followUp` queues, and JSON-serializable state snapshots (`exportState` / `importState`).
