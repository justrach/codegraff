# v0.302.44

This release adds two experimental SDK execution paths without replacing native Graff sessions.

- **Managed devices:** attach to an existing registered execution device, persist a submission receipt and cursor, and reconnect using device event replay. Prompt submissions are never automatically retried.
- **Worker-native execution:** run the shared Zig chat step through Wasm/JSPI with explicitly supplied host tools. The sandbox adapter tracks cleanup ownership separately from conversation state.
- **Optional tracing:** both paths use one metadata-only OTLP exporter. Prompts, generated text, tool payloads and credentials are excluded from exported spans.

## npm

Install the matching SDK with `npm install @codegraff/sdk@0.5.0`. The package adds `/managed`, `/otel`, `/worker` and `/worker-sandbox` entry points alongside the existing native, remote and ACP clients. Supported native platform packages remain optional dependencies.

## Boundaries

Worker-native execution is not full native-engine parity and does not yet checkpoint conversations. Managed recovery depends on the execution device and retained event tape; it does not guarantee exactly-once tool effects or migration after device loss. Installing the SDK does not deploy the optional managed trace collector. Existing native session behavior and authentication remain unchanged.
