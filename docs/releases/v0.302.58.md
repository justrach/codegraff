# v0.302.58

Faster, more reliable model discovery for ACP clients.

- **Model discovery never waits on a slow host.** `graff acp` startup and `graff/models` used to wait for every live model-catalog request, and a cold DNS lookup or slow TLS handshake could hold `initialize` for 10 to 40 seconds until the client gave up. Catalog requests now run in the background and write the disk cache. A cached catalog, fresh or stale, is used immediately and refreshed behind it; only providers with no cache wait, together, for at most 800ms. A request that misses the budget still caches its result for the next start. The Kimi account catalog is now cached for 6 hours. See ADR 0306.
- **`note_constraint` advertises its limit.** The tool description and the `text` field state the 240-byte limit that recording enforces, so a longer rule is recognized before the call rather than after a rejection (#1764).

Includes all changes from v0.302.57.
