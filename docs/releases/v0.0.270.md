# v0.0.270 (2026-08-22)

This release adds OpenRouter as a first-class chat seat, stops a Windows
panic that killed `edit_file` sessions, and makes both REPLs read like
the task instead of the event bus. It ships on top of 0.0.269 (GLM-5.3,
Vercel AI Gateway, codedb one-shots).

## OpenRouter

`OPENROUTER_API_KEY` (or `graff key set openrouter …`) is a built-in
OpenAI-chat seat at `https://openrouter.ai/api/v1`. Default model is
`anthropic/claude-sonnet-4.6` (1M context). Live `GET /models` overlays
the catalog (`context_length`; `include_reasoning` marks effort). Requests
send app attribution (`http-referer: https://codegraff.com`,
`x-title: graff`) so the client shows up in OpenRouter rankings. `/effort`
is the usual `reasoning_effort` field. This is not the Anthropic Messages
wire, the Responses wire, or image/video generation. Provider kernel 21.

## Windows path chmod (#606)

Zig 0.17's Threaded Io panics on Windows for `Dir.setFilePermissions`
instead of returning an error. `edit_file` / `write_file` restored the
pre-edit mode that way, so a mid-turn edit killed the whole REPL.
Mode restore now uses handle chmod (`File.setPermissions`, implemented
via NT attributes). Directory chmod is skipped on Windows, matching the
rest of the tree.

## Transcript is the task

Line REPL tool rows are decisions, not raw tool dumps (ADR 0021). Bookkeeping
tools stay off the transcript; todos render as a `WORKING` tree; scouts are
one-line cards. The TUI pager now paints numbered lists, `+` bullets, quotes,
task checkboxes, thematic breaks, and `_italic_` the same way.

## Distribution

Prebuilt archives are available for Linux, macOS, and Windows on arm64 and
x86_64. Both macOS binaries are Developer ID signed, hardened-runtime enabled,
and notarized by Apple; `SHA256SUMS` covers all six platform archives.
