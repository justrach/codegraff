Desktop updates download in the background and install when you choose Restart
to update. The application menu also provides a manual update check and an option
to turn off automatic downloads.

The macOS download includes a signed, notarized drag-to-Applications installer.
Earlier desktop builds need one manual installation to enable automatic updates.

This release also keeps drafts readable when chat panes are resized and prevents
duplicate desktop instances from opening separate copies of the workspace UI.
