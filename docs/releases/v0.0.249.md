# v0.0.249 (2026-08-12)

This release makes dynamically loaded tools real, carries complete turn usage
through the SDK boundary, and tightens multi-session reliability.

- **Loaded means callable.** Folded native tools now enter the active catalog
  immediately after their schemas load. The old path reported them as
  available while dispatch could never reach them (#492).
- **Complete usage events.** Turn events include cumulative input, output,
  cache-read, and cache-write tokens, generated into both TypeScript SDK
  surfaces from the canonical schema (#491).
- **Worktree-correct CodeDB Pro calls.** Relative codedb-pro paths resolve from
  the active Graff session directory rather than the daemon's launch directory,
  avoiding false missing-path reports after switching projects.
- **Clean non-interactive EOF.** A piped session with an unanswered
  `ask_user` exits cleanly when stdin closes instead of hanging (#478).
- **Lower fixed prompt cost and stronger concurrency coverage.** The skills
  catalog is capped before it enters the default prompt, and the release suite
  now runs concurrent interactive WebSocket tool loops across four sessions
  (#480).

The exact-key lookup optimization from v0.0.248 remains included.
