# Codegraff v0.302.35

Hosted-gateway models are priced from the gateway itself.

## Prices come from the gateway

The hosted gateway's model list now carries each model's price. graff used to
price gateway models from a snapshot baked into each release, so a model the
gateway added showed as unpriced, and a changed rate kept billing at the old one
until the next graff release. graff now reads the price from the catalog it
already fetches, for the session meter and for `graff models`, and keeps the
snapshot as the offline fallback.

`graff models` also listed gateway models under their direct-provider price, so
many showed `(unpriced)` or the wrong rate. It now shows what the gateway
charges.

## Clearer model errors

A model whose direct provider has no credential still fails rather than
switching to the gateway on its own, but the error now names the hosted route
when the gateway serves the model:

```
'<model>' is served by <provider>, which has no valid credential — run `graff login <provider>`, or use your Codegraff sign-in with `--model codegraff/<model>`
```

Flag errors now say `graff --help`.
