# v0.302.71

Computer use on macOS is now nanocua, an app graff ships itself. It replaces the adapter to Codex's computer-use plugins, which graff no longer loads.

- **graff ships nanocua on macOS.** Signed macOS releases carry `nanocua.app` beside `graff`, and `install.sh` and `graff update` place it in `~/Applications`. It's a separate app, so macOS's Accessibility and Screen Recording permissions go to it instead of your terminal. graff offers it as an MCP server below every config file: your own `nanocua` entry wins, and `graff mcp disable nanocua` turns it off. Starting the server does nothing until an agent's first tool call opens the app. (#1816)
- **`graff computer` and `/computer`.** See what's on, stop every agent at once, turn a switch off, ask to turn one on, or open macOS's permission prompts. Input starts off. Anything can read the state, stop nanocua or turn things off, but turning something on only asks: a card appears in nanocua's window, and only a real click answers it, because agents have shells and could run these commands too. (#1816)
- **Agents work in the background, inside one app.** By default an agent stays in one target app without moving your pointer or changing the front app. Several agents can share nanocua, each with its own target. (#1816)
- **Codex's computer-use plugins are no longer loaded.** `computer-use` and `unified-computer-use` are skipped even when enabled, and the adapter behind them is gone. graff shows no forms, so every MCP elicitation is now declined, including the defaults graff used to fill in for read-only requests. (#1815)

Known limits:

- A window that's minimized or on another Space can't be reached, because macOS refuses to capture it. The reply says so.
- The first click into a window that isn't key can be spent making it key, so click replies say "not confirmed".
- Tested live on TextEdit and on Chrome with a local page. Safari is untested.
- Computer use is macOS-only for now. Beta and unsigned releases carry no app.

Includes all changes from v0.302.70.
