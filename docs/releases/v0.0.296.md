# v0.0.296

This release improves desktop navigation, saved conversations, and interrupted work.

- Keep chat transcripts vertically scrollable while wide code and tables scroll within their own blocks.
- Open Agents as a workspace view, preserve chat drafts when switching views, and remember whether Tasks is open.
- Choose where web links open, search from the built-in Browser, and show clear feedback at the split-pane limit.
- Recover saved conversation titles and label saved snapshots separately from live execution.
- Recover from interrupted ACP turns and report clipboard and update failures more clearly.
- Keep automated GUI checks hidden by default; native foreground checks require explicit opt-in.
- Display saved MCP App results in isolated views. App-initiated tool calls remain disabled.
- Bound foreground shell waits, keep queued-turn activity visible, and improve server diagnostics and regression coverage.

The macOS desktop download includes a signed, notarized app. Native CLI archives are available for macOS, Linux, and Windows.
