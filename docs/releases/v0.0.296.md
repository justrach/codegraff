# v0.0.296

This release improves the desktop workspace, makes saved conversations and interrupted work easier to manage, adds MCP App result views and remote-control commands, and fixes terminal editing and background-job behavior.

## Desktop workspace and navigation

- **Agents gets a full workspace view.** Inspect agents and compose messages with more room. Switching between Agents and chats preserves open chat drafts, and each agent recipient keeps a separate message draft.
- **Tasks is optional.** Open or close the Tasks sidebar explicitly; the app remembers your choice and incoming task updates do not reopen it. Rows without details no longer show an empty expand control.
- **Chats scroll vertically.** Long text and links wrap within the conversation, while wide code blocks and tables scroll inside their own containers instead of pushing the entire chat sideways.
- **Choose where links open.** Desktop settings now let you choose the system browser or Codegraff's built-in Browser. The choice survives restarts, and built-in links open beside the focused chat.
- **Search from the Browser address bar.** Ordinary search terms are accepted alongside web addresses.
- **Clearer split-pane behavior.** The app explains when the four-pane limit is reached. Delayed keyboard-shortcut focus no longer overrides a newer chat or split selection.
- **More reliable folder navigation.** Pressing Enter in the folder picker no longer leaves it stuck displaying “Reading folder.”
- **Pasted images appear in user messages.** Supported staged images render directly in chat bubbles, with clear feedback if the image is no longer available.

## Conversations and interrupted work

- **Existing conversations regain useful titles.** Saved chats can recover titles instead of staying labeled “Untitled session,” with improved handling of long and Unicode titles.
- **Saved history is clearly labeled as a snapshot.** Opening a conversation that may still be running elsewhere no longer presents it as finished. The view reports that live status is unknown.
- **Refresh or continue deliberately.** “Refresh snapshot” updates saved history without starting another session. “Continue here” enables a follow-up explicitly. A failed refresh preserves the history already on screen, and empty saved conversations follow the same rules.
- **Recover after a stuck cancellation.** If a stopped desktop turn does not finish shutting down, its worker is retired before a replacement resumes the last saved conversation. Workspace and session settings are retained, late responses cannot interfere with the next turn, and cancellation errors remain visible. Unsaved output from the stuck worker may be lost.

## MCP App result views

- Connected tools that provide an MCP Apps UI can display an **Interactive MCP result** in the desktop transcript. Close and reopen the view while retaining the text and image output.
- In the terminal, **`/mcp apps`** opens the latest saved result view in the default browser.
- Views support result presentation, scrolling, resizing, and source links inside an isolated environment. They use the existing MCP connection and consent flow.
- This release does **not** allow a result view to initiate tool calls or insert messages into the conversation. Image-copy behavior depends on browser permissions and may require a copy-link or manual-selection fallback.

## Remote control

- **`graff remote-control`** makes sessions started by that process available to authorized remote clients.
- **`graff remote`** lists sessions; `new`, `send`, `answer`, `tail`, `cancel`, and `close` let you manage them from another machine.
- Stream progress, answer questions, cancel active work, and reconnect to session history. Remote access is permission-scoped, and unattended execution requires explicit opt-in on the host.
- Remote control covers sessions started by its supervisor; it does not attach to an arbitrary terminal session that was already running.

## Terminal, jobs, and workflow reliability

- **Image chips stay intact while editing.** Deleting or moving through an attachment no longer splits its marker, and remaining images are renumbered correctly.
- **Queued follow-ups keep live activity visible.** Adding another prompt no longer freezes the thinking indicator for the current turn.
- **Long shell commands yield control predictably.** An explicit timeout can shorten the foreground wait but cannot extend it beyond the automatic backgrounding limit. Long work can be followed through its background-job handle.
- **Clearer clipboard failures.** Clipboard access, extraction, and conversion errors are distinguished from a clipboard that contains no image.
- **More conservative server handling.** Legacy listeners are reported as candidates, recognizable server launches check for occupied ports, and unknown browser visibility does not justify automatically stopping a listening job. Discovery alone does not grant permission to terminate a process.
- **Git checks respect the command's target.** Shared-working-tree checks follow an explicit `git -C` or `cd` target instead of assuming the current directory.
- **Verification work survives checklist changes.** Replacing a checklist retains unresolved verification items, and completion tracking distinguishes a finished execution from verified task success.
- Additional publication and ownership checks are included, with the remaining limitations tracked below.

## Updates and macOS downloads

- Update settings explain why updates are unavailable and disable controls that cannot work in the current build, including when the app is still running from its disk image.
- Corrected packaged-executable handling so eligible installed builds can check for updates.
- The Apple Silicon desktop app, DMG installer, and both Apple Silicon and Intel macOS CLI binaries are signed and notarized. The app and DMG include stapled notarization tickets.
- CLI archives are also available for Linux and Windows on ARM64 and x86-64. The release includes checksums and the macOS automatic-update archive.

For the desktop, download **Codegraff-macos-arm64.dmg**, move Codegraff into Applications, and reopen it. Existing CLI users can run `/update` in the REPL or download the archive for their platform; an updated binary takes effect on the next launch.

## GUI testing and developer checks

- Automated GUI checks now use hidden, non-focusable windows by default, including packaged launch checks. Unexpected window presentation or activation is treated as a test failure.
- Visible-but-inactive test mode is an explicit opt-in. It can still cover other apps. Native focus, keyboard/mouse input, and fullscreen checks require a separate foreground opt-in; hidden checks do not establish that coverage. Missing permission-dependent coverage is reported explicitly.
- Added native macOS GUI CI and expanded regression checks for workspace switching, snapshots, links, images, task rows, MCP Apps, cancellation, and updates.
- Isolated terminal-test clipboards, fixed quiet clipboard-input hangs and Linux cancellation fixtures, corrected fresh-connection replay expectations, and bounded MCP connection-reuse test teardown.
- Packed SDK installation tests use the expected dependency versions and local fixtures. Live end-to-end evaluation fixtures and scoring checks were also expanded.
