# v0.302.42

- Reasoning-only replies that reach the output limit no longer leave empty assistant messages in later requests or saved history. Valid partial answers and tool-call reasoning remain intact.
- ACP subagent activity shows the resolved worker model before child activity starts, including fallback selections. Older activity records remain readable.
- Large saved sessions load correctly, MCP task deadlines match bounded execution, and streamed progress and oversized tool results are preserved.
- Parked commands retain their outcomes across continuation, compaction failures are reported without ending the session, and repeated runaway replies have bounded recovery.

This release integrates current main with the existing release fixes. Release builds verify cached artifact restoration before packaging.
