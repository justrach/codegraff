# v0.302.64

An expired Anthropic Console sign-in is skipped, and the error says so.

- **No more dead Console token.** When a Console sign-in's token has expired and no refresh token is stored, `ant auth print-credentials --access-token` warns but exits 0 and prints the same expired token. graff took that as a successful refresh, so it kept using the token, or kept it as the fallback behind a Claude plan, and every request came back 401. A renewal that returns the old token now counts as failed: the expired sign-in is neither used nor kept as a fallback, and mid-session graff stops sending it.
- **The error names it.** "Anthropic Console sign-in has expired: run `graff login console` again. Your sign-in is not affected." After a plan handoff it says the fallback Console sign-in has expired, and when a plan runs out with no fallback for that reason: "Anthropic plan is out of quota, and the Console sign-in that would take over has expired: run `graff login console` again, or wait for the plan to reset." (#1781, ADR 0310)
