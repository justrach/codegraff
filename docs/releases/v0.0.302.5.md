# Codegraff v0.0.302.5

This update keeps dry-run route checks aligned with the active selection. When
a route is explicitly qualified, a check now retains that qualification while
testing availability. The displayed result therefore reflects the route a
subsequent request would take.

The release includes the command-line archives and checksums. The macOS desktop
download is published after signing, notarization, stapling, and verification;
its update manifest is checked against the same archive attached to the release.

See the [changelog](https://github.com/justrach/codegraff/blob/v0.0.302.5/CHANGELOG.md)
for the full list of changes.
