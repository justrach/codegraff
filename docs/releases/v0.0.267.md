# v0.0.267 (2026-08-19)

Background bash jobs wait like grok-build: one `bash_output(wait_ms>0)`
blocks until the process exits (10h cap). The 30-second poll loop that
turned a CI wait into hundreds of model calls is gone (ADR 0010).

## Wait for exit, not the next byte

- `wait_ms = 0` (or omitted) is still a snapshot
- `wait_ms > 0` waits for **exit**, not new stdout
- The old `1…30000` values are promoted to the 10-hour cap
- `agent_output` uses the same deadline
- Schema and spawn text say: do not poll; one wait covers exit
