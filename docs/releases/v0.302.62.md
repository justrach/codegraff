# v0.302.62

`rlm`'s `llm_query` works on Claude Agent.

- **Sub-queries run on Claude Agent.** Inside `rlm`, `llm_query` used to answer "llm_query is not available on Claude Agent" because that provider has no HTTP endpoint. Each sub-query now runs on its own short-lived `claude` process with no tools, the way titles and recaps already do, and the text comes back as usual. The chat's own `claude` process and its prompt cache are never touched (#1777, ADR 0309).

Includes all changes from v0.302.61.
