# v0.302.69

Peer mail stops rewriting history that was already sent, workers can use gateway models, and `graff harness-tree` shows the harness as one value.

- **Reading peer mail keeps the conversation intact.** After a turn read its inbox, graff removed every peer wake line from the whole history, including ones the model had already been sent. That rewrote history the provider had cached: on Claude Agent every woken turn started a fresh Claude Code process, and on other providers it changed the cached prefix. Only wake lines the model was never sent are removed now. (#1799)
- **Workers can use gateway models and name their own provider.** `--subagent-model <model>` with `--subagent-provider codegraff` accepts a model the gateway serves even when the built-in catalog does not list it, a persona pinned with `model: <provider>/<model>` runs on that provider, and a worker's calls on another provider report their cost. (#1769)
- **`graff harness-tree show|digest|check|apply|diff`** reads the files graff loads to decide how it works (the instruction file, skills, subagents, scripts and hooks) as one tree you can inspect, compare and apply. (#1770)
- **MCP over HTTP: cancelling a request retries its notice** when the machine is briefly out of local ports, instead of dropping it. (#1796, #1794)
- ADR 0308 records that a cheaper scout worker is an opt-in persona, not a default route. (#1771)

Includes all changes from v0.302.68.
