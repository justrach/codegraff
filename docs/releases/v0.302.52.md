# v0.302.52

Release binaries now use Zig ReleaseSafe, keeping runtime safety checks enabled.

- A clearer terminal prompt and status strip, warm amber accents, and distinct active checklist styling make ongoing work easier to follow.
- Markdown emphasis renders in streamed replies and agent reports instead of leaving formatting markers literal.
- `/workers` opens a read-only subagent browser: click or press Enter to inspect activity and reports, use arrow keys to scroll, Escape to return, and q to close. Tool bodies expand on request. `/agents` still lists agent types.
- Narrow terminals keep operational modes visible before optional metadata. Plain output stays free of terminal control sequences.
- Release publication waits for CI on the exact tagged commit.

Includes the fixes from v0.302.51. The ordinary line REPL and the separately installed fullscreen terminal UI remain distinct.
