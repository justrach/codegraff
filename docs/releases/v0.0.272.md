# v0.0.272 (2026-08-22)

The Windows UTF-8 switch now covers the line REPL prompt, not only the
fullscreen TUI. It ships on top of 0.0.271 (`#607` at process start).

## Line REPL and standalone `graff-repl` (#607)

0.0.271 set CP 65001 in `enableVtOutput()` (before chrome) and in the
fullscreen TUI's `enterRaw`. The default `graff` prompt still went through
`src/term.zig` `tty.enterRaw` (readline, `/model` pickers, `/login`), which
only flipped input flags. Nested raw mode could therefore print box-drawing
as CP437 even after the process-start switch.

That enterRaw now sets CP 65001 and restores the prior pages on the way
out. Standalone `graff-repl` (which never visits `src/main.zig`) calls
`enableVtOutput()` before zigzag raw mode. VT processing is enabled on
stderr as well as stdout, so YOLO/notices on fd 2 get the same treatment.
