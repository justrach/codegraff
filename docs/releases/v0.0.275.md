# v0.0.275 (2026-08-24)

OpenRouter usage now attributes to the app in public rankings.

Requests to OpenRouter carry `HTTP-Referer: https://codegraff.com`,
`X-Title: graff`, and `X-OpenRouter-Categories: cli-agent,programming-app`
(max 2 per request; unrecognized slugs are dropped server-side, so only
recognized Coding-group categories are sent). The Vercel AI Gateway path
keeps its original referer + title headers only.

Also in this release:

- TUI: pressing Esc with a draft in the composer never kills a live turn.
- Agent: degenerate empty completions and keep-alive-only streaming bodies
  are retried instead of surfacing as blank answers.
- codedbpro tool accepts native-shaped `{path}` arguments and stops filing
  caller errors for that shape.
