# v0.302.68

Claude Agent compaction writes a real summary again, and a prompt after a finished turn keeps its images.

- **Compaction summarizes instead of carrying on.** Claude Agent runs compaction on a fresh Claude Code process. When it was cut in the middle of a tool loop, the summary request was folded into the conversation text and followed by "Continue from where the checkpoint ends." In a long chat the model kept working on the task, or asked you a question, and that reply was installed as the summary. The summary request is now always sent as the request. (#1792, #1793, #1797)
- **A prompt after a finished turn is read as a prompt.** The same fault hit a new message sent after a turn that ended on a tool call such as `attempt_completion`: it joined the old conversation as text, and its images arrived as "[image]". The message now reaches the model as itself, images included. (#1792, #1793)

Includes all changes from v0.302.67.
