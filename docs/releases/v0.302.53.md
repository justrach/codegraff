# v0.302.53

Smaller release binaries without changing prompt content or runtime safety checks.

- Embedded runtime pages and installer resources are compressed until needed.
- Prompt variants share their common text, and optional tool catalogs are built on first use rather than stored repeatedly.
- Release builds keep runtime safety checks while reducing duplicated library code.
- Local learning is excluded from release binaries; development builds retain it.
- Routed requests use stable session affinity, and usage prices follow the router's published catalog.
- Workflow synthesis preserves its tool catalog when entering the final report-only phase, while refusing further tool execution.

Includes the changes from v0.302.52.
