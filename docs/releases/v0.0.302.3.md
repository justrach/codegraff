# Codegraff v0.0.302.3

Hotfix on 0.0.302.2. First launch of the desktop app, screenshot paste, and
auto-update to four-part versions were all broken in ways that looked like
something else (MCP, clipboard, “check your connection”). This cut fixes
those, and ships graff-native task workspaces.

## Desktop: first launch no longer races MCP, and `graff` is on PATH

Packaged launch started two overlapping `graff mcp install` processes. The
loser hit a non-blocking flock and showed **MCP setup incomplete** while the
winner was still working. Setup now runs once per launch, waits on the lock,
and is not stacked on the engine-launcher path.

The engine shim also only patched the GUI process’s shell rc, so a notarized
`.app` left `graff` missing from a new Terminal login shell. Launch now writes
zsh and bash login *and* interactive files, shims Homebrew `/opt/homebrew/bin`,
`/usr/local/bin`, and `~/bin` when those directories are writable, and does
not gate that work on MCP or notarization. Open a new terminal after install
and `graff` should resolve.

Retry from **Tools → Configure MCP clients** or **Install codegraff terminal
command** if an older build already failed.

## Ctrl-V screenshot paste

Pasting a screenshot into the REPL or TUI printed:

`clipboard helper unavailable — use Edit > Paste for text or /image <path>`

The macOS helper still writes a PNG under `/tmp/graff-clip-*.png`. It shared
bash’s Esc-cancel flag, so a leftover Esc killed `osascript` and classified
the paste as a dead helper. Clipboard export now ignores that flag. Terminal
Edit → Paste is still text-only; Ctrl-V is the image path.

## Auto-update to `0.0.xxx.x`

Checking for updates could throw **Could not check for updates. Check your
connection and try again.** Four-part hotfix versions (`0.0.302.3`) are not
semver, and electron-updater refused them. The desktop feed now maps
`0.0.302.3` → `0.302.3` so a 3-part install sees the hotfix as newer. The zip
name stays `Codegraff-0.0.302.3-macos-arm64.zip`. The native updater compares
the fourth segment the same way. `0.0.302` < `0.0.302.3` < `0.0.303`.

## Task workspaces are graff-native

New task workspaces copy gitignored files from `.worktreeinclude` or
`.graff/workspace.toml` `include`, and run `scripts.setup` / `run` / `archive`.
Desktop **Tools**: New task workspace, Run, **Land** (squash onto the base
branch, then remove the checkout), Archive (clean duplicates only). The agent
never deletes a named tree. Review stays the Changes pane on that worktree.

Config and env are graff’s:

- `.graff/workspace.toml`
- `.worktreeinclude`
- `GRAFF_WORKSPACE_NAME`, `GRAFF_WORKSPACE_PATH`, `GRAFF_ROOT_PATH`,
  `GRAFF_WORKSPACE_PORT`

No other product’s settings file or environment names.

## Shell jobs from 0.0.302.2, still in this cut

Persistent `shell` / `bash_output` jobs snapshot immediately (`wait_ms`
ignored) and stay on `/jobs`. Finite jobs still wait until exit.

## Install

macOS CLI tarballs are Developer ID signed and notarized. The desktop app is
the notarized DMG / zip on the same GitHub release. `install.sh` and
`graff update` pick up this tag.
