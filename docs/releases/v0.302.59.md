# v0.302.59

More reliable streaming for large responses.

- **Partial SSE progress no longer looks like a stall.** A large event can arrive steadily before its next newline. Both HTTP/1 and HTTP/2 now track response-body byte progress so those events are not discarded and their requests replayed (#1765).
- **Real stalls still recover.** Cancellation and genuine inactivity detection remain in place. Unfinished events have bounded assembly time and size; local assembly-limit failures stop rather than retrying a request that cannot repair them.

Includes all changes from v0.302.58.
