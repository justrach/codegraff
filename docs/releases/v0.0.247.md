# v0.0.247 (2026-08-10)

A focused REPL polish and input-reliability release.

- **Quieter interactive startup.** Normal sessions keep the banner and actionable safety notices while hiding verbose login, MCP/config, project-instruction, imagegen, presence-bookkeeping, and raw tool lifecycle diagnostics. Set `GRAFF_REPL_DEBUG=1` before launch to restore startup and runtime diagnostics; `/debug` still toggles tool and presence detail during a session.
- **Shared-worktree ownership is clear, not buried.** When another live Graff session owns the checkout, startup presents a structured callout with the active session, PID, age, goal, and the `graff -w` isolation action. The collision checkpoint remains enforced.
- **Multiline `ask_user` paste is reliable.** The answer editor now completes terminal paste setup before showing its prompt, so an immediate bracketed paste preserves every line instead of submitting only the first.

JSON/one-shot protocol behavior is unchanged. The release includes real-PTY coverage for launch debug mode, parallel cancellation, descendant cleanup, and immediate multiline answers.
