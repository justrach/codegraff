## Pasted images reach the model through ACP clients

An image attached from an ACP client (the desktop/native chat surfaces)
arrived at the model as literal `@[path]` text; the pixel payload was
never staged, so vision turns silently lost the image. The ACP turn
path now runs the same promotion the mainloop and REPL already do —
`@[image]` markers stage into native provider vision blocks, and the
message is built from the staged queue. Non-image `@[path]` entries
stay literal text so the agent still opens them with its tools. Queued
prompts are covered: the attachment block is baked in at submit and
queued prompts drain through the same turn path. One regression test
covers both the image and non-image cases.

## Peer wake is advisory, not a command (#708)

The one-line `[peer]` wake appended to a user turn ended in the
imperative `peer_message action=inbox`, so a trivial turn (a bare
greeting) made the agent spend the turn reading the mailbox instead of
replying. The wake now says messages are parked and gives the read
hint inline as a when-relevant option, short enough to stay one
unwrapped dim row; an empty inbox carries no read command at all.
Detection is untouched (prefix-based), so compact/peek paths and
resumed transcripts are unaffected.

## Invalid JSON after a failed parallel bash (#711)

A parallel `bash` pair that returned HTTP 404 left a tool result in
history, then the next Codex request failed with `Invalid body: failed
to parse JSON value`. Send-time normalization now coerces
`function_call.arguments` and non-string `function_call_output.output`
to JSON strings before the body is built.

## Device-wide `/resume` (#712 / ADR 0059)

Bare `/resume` and `/sessions` listed only `.graff/sessions` under cwd.
Saves from `$HOME` (`~/.graff/sessions`) looked like they were gone.
The picker and `/sessions` now show cwd first, then home, labeled with
origin. Resuming a foreign save restores conversation history into the
current cwd and says so — `read_file` / `edit_file` / `bash` do not
silently switch trees.

## Named-source gate and turn replay (#714 / ADR 0060)

A user question that named a source file could replay for dozens of
turns. The nudge walked all history, so `SPEC.md` in an earlier
message re-armed the gate on every later completion, and
`repl_convo.adopt` appended the frontend's trailing user row even
when it was already the latest ask. The gate is now per unanswered
mention. Identical user injects are skipped; three copies fail closed.

## Fullscreen `/goal` retires on completion (#716)

A typed TUI `/goal` was published as a standing session flag, so
`attempt_completion` recorded the finish and left the objective
active. `/resume` restored it and the next unrelated prompt was
steered toward finished work. The pager now sends `status` / `pause` /
`resume` / `clear` through the same lifecycle as the line REPL;
typed goals stay non-standing.
