# Codegraff v0.302.40

This release brings the pending recovery, configuration and update changes together.

- Interrupted streams retry with separate drop and stall budgets; ACP preserves the partial reply for the next turn and resume.
- Workspace skills are available in headless runs. Runaway replies recover without replacing bounded output-limit continuation.
- Claim capacity errors and keyless status list held claims and eligible releases without evicting active owners.
- MCP off-lists and `graff mcp list --json` expose configuration provenance without secret values; project precedence is preserved.
- Stored interactions continue from verified history, with complete prompt usage accounting. Compaction preserves unread tool results.
- ACP authentication failures carry fixed, route-specific sign-in recovery metadata.
- The installer refreshes the code-navigation companion with checksum validation and atomic replacement.
- Hosted compaction validates decisions and retained context, but remains explicitly opt-in with `GRAFF_CLEF_COMPACT=1`. Local-summary defaults and provider-owned compaction routes are unchanged.

Includes the unattended-run recovery and structured one-shot results from the unpublished v0.302.39 draft.
