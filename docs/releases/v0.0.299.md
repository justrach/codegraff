# Codegraff v0.0.299

The MCP Apps task result view now matches the codegraff.com design system.

## Paper instead of emerald chrome

`run_task` results in MCP Apps hosts use the site palette: warm paper, rice surfaces, ink type, coral for Graff, cobalt for links, mustard focus rings. Radii stay small. Touch targets stay at least 44px. The view still cannot fetch webfonts or run tools. Light and dark follow the host.

## Talk while a command runs

Type a follow-up during a foreground shell wait and the command moves to the background instead of sitting for 120s or dying on force-steer. Esc with no queued line still kills it.

## One shell tool

`bash`, `bash_output`, and `bash_kill` collapse into one catalog `shell` tool with `action=run|output|kill`. The old names still dispatch. This is not a PTY: you cannot type into a running process. Type in the composer to steer the turn.

The rest of 0.0.298 is unchanged.
