# Codegraff v0.0.299

The MCP Apps task result view now matches the codegraff.com design system.

## Paper instead of emerald chrome

`run_task` results in MCP Apps hosts use the site palette: warm paper, rice surfaces, ink type, coral for Graff, cobalt for links, mustard focus rings. Radii stay small. Touch targets stay at least 44px. The view still cannot fetch webfonts or run tools. Light and dark follow the host.

The rest of 0.0.298 is unchanged.
