# v0.302.73

ACP now preserves the distinction between literal prompt text and an explicitly selected command.

- A client can send per-prompt command intent so slash-prefixed prose reaches the agent unchanged instead of being rejected or dispatched locally.
- The same intent gates goal, review, issue, loop and side-request expansion, so ordinary text cannot accidentally invoke those commands.
- Explicitly selected commands still execute. Clients that omit the marker retain their existing command syntax (#1817, ADR 0315).
