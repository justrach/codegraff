# v0.302.74.3

This hotfix resolves repeated Responses compactions on large encrypted state blobs and fixes cross-format model switching with context retention enabled.

- On full-history Responses requests, local byte estimates of opaque `compaction` and `reasoning` `encrypted_content` no longer override the provider's reported token usage and force repeated compactions (#1686). Visible text, schemas, tool outputs, and images retain their floor, and missing or chained usage keeps conservative ciphertext protection.
- Switching across wire formats with `keep_context` enabled expands opaque compaction state from its checkpoint before translating history, drops intermediate tool-accompanying status preambles so they do not remain as consecutive tool-less assistant replies, and preserves `attempt_completion` answers (#1833).
