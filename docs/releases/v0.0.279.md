## Native app is an ACP client

`apps/native` is a merjs desktop shell around Beautiful UI primitives.
It used to proxy `graff serve` NDJSON. That needed a second process and
still stacked a second "Thinking" spinner on the thinking chip.

It now owns one `graff acp --yolo` child via Next.js `/api/acp`. Mid-turn
`session/update` notifications map onto the same chips the screenshot
already showed:

| ACP `sessionUpdate` | primitive |
| --- | --- |
| `agent_thought_chunk` | `ThinkingState` |
| `tool_call` / `tool_call_update` | `ToolChips` (+ edit diffs) |
| `agent_message_chunk` | `StreamingText` |

`graff serve` is not required. `session/cancel` sets Esc. A model change
respawns the child. Approvals are off this path (`--yolo`); ACP has no
`session/request_permission` yet.

## `graff acp` streams mid-turn (ADR 0032)

v0 ACP wrote one final `agent_message_chunk`. During `session/prompt`
the agent now installs a translating writer on `root.out` / `g_out` so
`--json` events become v1 session updates (thought, text, tool_call,
tool_call_update). Stub turns that emit nothing still write the v0 final
chunk. Zed stays on protocolVersion 1.

## Embedding graff

A host embeds graff by spawning the binary, not by linking a library.
[docs/embedding.md](../embedding.md) names the two APIs: `graff acp`
(ACP v1 JSON-RPC; thought / tool / text `session/update`) and
`@codegraff/sdk` `Harness` (`graff --json`). `@codegraff/sdk/acp` is the
spawn plus write/read. `--no-local-tools` still gates local bash/file
tools on a trusted host. Modified AGPLv3: a hosted/SaaS embed is a
legal event.

## Standing constraints (#638)

`/never` is an ACP slash command (`available_commands_update` after
`session/new`) and is intercepted as a local prompt, so a native/Zed
user can list and retire rules without the REPL. On a TTY, bare
`/never` opens a `/model`-style searchable picker (constraint text
first, id second) and asks twice before a tombstone. ACP / pipes keep
the text list. `rm` accepts an id or a unique text fragment. An
explicit "forget / override that rule" in the next user message
tombstones the matching item before the model turn (ADR 0033).
`note_constraint` stays append-only.

## Background job waits (#640)

Any `bash_output` / `agent_output` `wait_ms>0` waits for exit (10h).
A model that passes a mid-range "safety timeout" (60s–240s) no longer
gets `[job N: running]` back mid-job and a second billed hop.

## Compaction pin budget (#581)

The live unresolved prompt (and its images) stays pinned. If that
pinned suffix alone is already over the 8k keep budget, compaction
announces once and then stays quiet for the rest of the turn instead
of reprinting `[compaction skipped…]` every cycle. Server-side blob
prune / explicit compact refuse a cut that would drop that pin.

## Tier-1 wall (#641)

`eval-tier1.sh` runs the 17 tuiguard PTY probes in a 4–8 process
pool, counts the suite and the named invariants by scanning the
unfiltered test artifact (no filtered recompiles, no second suite
execution on a zig cache hit), and accepts `--only tui,tuiguard`.
