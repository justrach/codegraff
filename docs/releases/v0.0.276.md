# v0.0.276 (2026-08-25)

RLM + mid-stream spec-ptc is the default harness loop.

`graff` now advertises the `rlm` REPL (persistent binds, `subagent()`,
`llm_query`, speculated host calls as the script streams). `--old` /
`--no-rlm` restore the previous structured-only catalog.

This is the Zig port of [alexzhang13/spec-ptc](https://github.com/alexzhang13/spec-ptc)
and [alexzhang13/rlm](https://github.com/alexzhang13/rlm). Prime Agent's
IPython/ZeroMQ kernel is not in the process; persist + `subagent("task")`
are the only Prime-shaped pieces, still in Zig.

`--schema` and the 64-cell tool-catalog kernel do not list `rlm` as a
new always-on tool — it still folds behind `load_tool_schemas`.
