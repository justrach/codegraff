# v0.302.45

- **Context savings on the meter.** The ACP `usage_update` now carries `_meta["codegraff/savings"]` once any count is nonzero: tool-result bytes kept in handle files instead of the conversation, estimated context tokens freed by compaction or an emergency trim, and input tokens the provider served from its prompt cache. They are measured counts for the process, not a model of what another agent would have spent. Harness shows them next to its context meter.
- **`render_html` says saved, not shown.** The tool result reports the page as saved and asks the model to say it is ready to open. No client acknowledges display, and a client that shows no views gets the same line. The `[Rendered view](path)` prefix and the `graff/view` metadata are unchanged.
- **`workspace use` and project instructions.** The tool now says instructions follow the tree you switch to, which is what hot context does. The `core/instructions` update names the directory its file came from, and the change probe notices a switch even when both files match in size and modification time.
- Retains all changes from v0.302.44.
