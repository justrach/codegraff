# Codegraff v0.302.37

ChatGPT sign-in keeps saved tokens out of the sign-in URL.

## The sign-in URL carries no saved token

Signing in to ChatGPT again (`graff login chatgpt`) put the saved ID token in
the sign-in URL. graff didn't print that URL, but it handed the URL to the
browser opener as a process argument, which any process on the computer can
read.

The URL now carries only the account's email as a hint. The app id issued at
the first sign-in still skips the consent screen, and a sign-in that comes
back as a different account is still refused. Because the URL holds nothing
secret, graff always prints it, so you can open the sign-in for a headless
machine on another computer.

## A renewal for another account is refused

When graff renews a ChatGPT sign-in, it now checks that the renewed identity is
the same account. If it isn't, graff records the mismatch and doesn't use the
new tokens; sign in again to continue.
