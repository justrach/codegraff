# v0.302.46

- **Images over ACP reach the hosted default models.** An ACP client's `image` prompt blocks were staged only for models in `vision.zig::visionModel`, which didn't list the hosted default models, though the hosted catalog marks them as taking images. Pictures pasted into a client were dropped before the model saw them. They're now in the list.
- **A worker's report survives a failed checkpoint.** After a worker runs, graff saves its state for follow-ups; when that save failed, its error replaced the worker's report and usage, which came back as only "error: FileNotFound" (#1671). The save is now best-effort: the report and usage stand, with a note that `agent_message` and resume can't continue the worker and why. An error during setup now says the worker didn't start and no tools ran.
- **A client's own cancel isn't the user's.** A `session/cancel` carrying `_meta["graff/cancelSource"] = "client"` ends the turn with "[response ended early: stopped by the client, not the user]". A bare cancel, or one marked `"user"`, still reads as the user's (#1611).
- **Computer Use and bare processes.** When an app is rejected because its window belongs to a bare process (`java -jar`, a script interpreter, a dev server), graff adds a note: such apps can't be selected even while their window is open, the rejection doesn't mean the launch failed, and the app should be checked another way or reported as not inspectable.
- Retains all changes from v0.302.45.
