# v0.0.256 (2026-08-15)

Hotfix: Super/modifier Kitty CSI-u leftovers (`3u7444;9u7441;10u`) were
typed into the transcript and sometimes decoded as Escape/Ctrl+C, which
killed the turn.

- Any orphan CSI (`…u`, `…M`, arrows) after a split ESC is consumed as
  ignore/mouse, never as letters.
- TUI stdin is appended to `.graff/tui-traj.jsonl` (hex, rotated at 512KiB)
  and the last visible frame is written on exit.
- Shift+9 / Shift+0 type `(` / `)` (Kitty reports the unshifted key).

Bare `graff` stays the line REPL. `graff tui` is the pager.
