# Unlimited model-call budget by default, wider default concurrency

v0.0.212 removes a run-wide ceiling that could halt an otherwise healthy
session. It is a small, compatible hotfix on top of v0.0.211.

## Run budget no longer wedges a session

- The invocation-wide model-call budget defaulted to 256 calls and never reset
  for the life of the process. A single workflow fan-out could reach that
  ceiling, after which every later turn failed at admission with
  `RunBudgetExhausted` before it ever reached a model.
- The model-call count ceiling now defaults to unlimited. The Workflow layer
  keeps its own 1000-agent runaway backstop and the recursion-depth guard is
  unchanged, so the safety that actually prevents runaway loops stays in place.
- An explicit `--max-model-calls N` or `GRAFF_MAX_MODEL_CALLS=N` with a positive
  N still enforces a hard ceiling for anyone who wants one. A value of 0 now
  means unlimited.
- Default in-flight model-call concurrency rises from 4 to 8, so parallel
  subagents and workflow stages admit more work at once.

## Validation and distribution

- The full Zig test suite, including a new test that proves an unlimited budget
  never exhausts across a thousand admissions, passes. Formatting and build
  checks pass.
- Both macOS binaries are Developer ID signed and submitted to Apple's
  notarization service before this draft is published.
- Every published archive is covered by `SHA256SUMS`.

```sh
curl -fsSL https://raw.githubusercontent.com/justrach/codegraff/main/install.sh | sh
```
