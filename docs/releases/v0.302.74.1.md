# v0.302.74.1

- A provider or model switch expands opaque compaction state back into the exact
  input it was compacted from, instead of replaying it to a seat that did not
  mint it. Switching after compaction no longer fails against ciphertext the new
  backend cannot decrypt, and the whole conversation after the compacted window
  is preserved (#1829).
- Sessions with no usable checkpoint are unchanged: one rejected request, history
  left intact, and an explanation of the blocked state.

This release changes how a switch recovers. It does not make rejected state
decryptable — a backend that will not accept a blob still will not, and detailed
diagnostics and conversation contents stay local.
