# v0.302.61

Claude Agent: Claude models through your own Claude Code login.

- **Sign in once.** `graff login claude-agent` (or `/login claude-agent` in a session) checks that your installed Claude Code (`claude`) is signed in and records the choice. graff never reads Claude Code's credentials; if Claude Code has no login, it says to run `claude auth login`.
- **graff's harness, your Claude plan.** graff runs your `claude` with its built-in tools, settings, hooks, CLAUDE.md, memory and auto-compaction off, and offers graff's own tools. Tool calls go through graff's loop as usual: approvals, parallel batches, ACP and subagents work unchanged. graff's history stays the source of truth, so switching between Claude Agent and any other model keeps the conversation. Calls are flat-rate on a Claude plan (ADR 0309).
- **It is your Claude plan in `/model`.** Claude Agent lists `claude-opus-5-5`, `claude-fable-5-1`, `claude-sonnet-5-5` and `claude-haiku-5-5` (and the 5.0 models Claude Code still offers) under their real names, and those names route to it once chosen. `anthropic/<model>` still reaches the API route, and a session saved on it keeps it.
- **Subagents wait for their workers in lean mode.** A request for subagents loads `agent_output`; lean mode used to drop it from the tool list, so a turn that started background workers could end before they reported.
- **A Linux CI crash is gone.** Catalog tests wait for the workers they abandon, which had crashed the test job with SIGIO (#1772).

Claude Agent needs Claude Code 2.1.248 or newer, installed and signed in on the same machine. `GRAFF_CLAUDE_AGENT_PROMPT=claude` keeps Claude Code's system prompt and appends graff's.

Includes all changes from v0.302.60.
