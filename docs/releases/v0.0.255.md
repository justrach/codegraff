# v0.0.255 (2026-08-14)

Hotfix: the Grok-style pager was painting leftover mouse CSI
(`4M39;33;23M…`) into the thinking line whenever the pointer moved.

- Disable any-event mouse (`1003h`). Clicks and wheel still work.
- A split ESC at the end of a stdin read is no longer treated as Escape.
- Orphan `b;x;yM` / `<b;x;yM` reports are consumed as mouse events, never
  inserted as letters.

Bare `graff` stays the line REPL. `graff tui` is the pager.
