`args: ["login"]`). Clients without a terminal get no unusable method.
`authenticate` stays unused — the client re-spawns `graff login`. ACP
Registry listing still needs a PR on `agentclientprotocol/registry`;
leave #613 open.

(`install_agent_tool`, `local__<name>`, `--dry-run`). Skills stay
instructions (ADR 0039).

due-claim and a TUI idle wake. `/loop` stays standing-goal.

Channel workers speak JSONL (outbox + wake only). Inbound
`{"type":"message","text"}`; `/adapter send` emits `{"type":"send","text"}`.
