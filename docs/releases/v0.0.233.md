# Honest outcomes everywhere: iOS trust, MCP negotiation, and faster autosave

v0.0.233 is a fix batch driven by a full triage of the issue tracker — six
branches, each adversarially reviewed before merge.

## iOS: the app stops making things up (#286, #316, #310, PR #357)

- Failed sessions no longer render a green "Done": outcome is now recorded in
  the transcript per turn and liveness can only say "Ended"/"Unknown", never
  invent success. A failed session list fetch keeps prior statuses instead of
  rewriting them.
- Fresh signed-out installs show an honest empty state with a sign-in button
  instead of fabricated demo sessions posing as account history.
- Session sync is now an ordered actor: per-session serialized writes,
  revision guards so an older payload never clobbers newer state, and
  revision-scoped tombstones so deleted sessions stay deleted (but a
  post-delete recreate can sync again).

## MCP companion: no more silent legacy downgrades (#327, PR #358)

- The modern-protocol probe only falls back to legacy on a real "I don't
  speak that" answer. Transport errors propagate and retry; any fallback is
  surfaced. The probe timeout now covers a cold child start (5s default,
  `GRAFF_MCP_PROBE_MS` to tune) — 600ms degraded the companion on every run.

## GUI: `**` can no longer leak into linkified URLs (#197, PR #359)

- Root cause found beyond the originally fixed case: an unpaired `**` opener
  (think `**kwargs`) mis-paired with a later URL's bold delimiters. Emphasis
  pairing is fixed (earliest-starting pair wins, nesting no longer abandons
  the enclosing pair) plus the linkifier defensively strips paired emphasis
  delimiters at match boundaries — legitimate trailing `*`/`~` in URLs still
  survive.

## Faster turns in long sessions (#273, PR #360)

- Autosave skips when nothing changed and moves the file write to a
  coalescing background writer (drained on exit/quit/clear/switch), so the
  prompt path no longer pays O(total-history) disk latency every turn.
  Per-save error tickets keep `/save` failures accurate.

## Fleet: per-persona and per-spawn model pinning (#292, PR #361)

- Personas can pin a model and the `subagent` tool takes an optional `model`
  override. Precedence: spawn > persona > session ladder. Unavailable pins
  degrade with a stated reason. SDKs regenerated.

## Also

- `--max-model-calls` help no longer claims a "default 256" that never
  existed — the real default is 0 = unlimited (PR #362, related to #217).
