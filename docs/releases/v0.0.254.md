# v0.0.254 (2026-08-14)

This release ships the Grok-style fullscreen pager that 0.0.253 held back, and
the Claude/Cursor adopt path that goes with it. Bare `graff` stays the line
REPL; `graff tui` (and TTY `graff repl`) is the pager.

- **`graff tui` is a Grok-style fullscreen pager.** It takes the alt screen
  with a wrapped composer (multiline, Ctrl+Z undo, image chips after `› `),
  folded `◆ Called N tools` cards that click open to a thought-style preview,
  Shift+←/→ jumps between user turns, Ctrl+J/K line scroll, and a searchable
  effort overlay next to the model picker. Markdown pipe tables render as
  box-drawing. Image paste/drop becomes `[Image #N]` chips with a metadata
  preview. A headless `Term` driver lets tests type, click, and hover without
  a PTY. Second Ctrl+C during a turn quits after the first cancels it.
- **First-run adopt copies Claude/Cursor MCP servers and skills.**
  `/import-claude` (and `graff mcp import`) writes them into `~/.codegraff`
  and the current repo. The first interactive start does this once; the
  command stays for a later rescan. Hooks are copied, not merged into
  `.harness/settings.json`.
- **Hosted tool lines stay inspectable.** Live `⚙ read path` / `✓ read | preview`
  rows carry the argument or a one-line result so the pager can harvest them
  into folded history without a raw JSON dump.

macOS CLI builds are Developer ID signed and Apple notarized. The desktop app
(`.dmg` / updater tarball) is signed, notarized, and published alongside the
CLI assets. Verify a download with:

```sh
codesign --verify --strict --verbose=2 graff
```
