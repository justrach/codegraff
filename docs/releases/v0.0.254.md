# v0.0.254 (2026-08-14)

This release ships the Grok-style fullscreen pager that 0.0.253 held back, and
the Claude/Cursor adopt path that goes with it.

- **`graff tui` is the fullscreen pager; bare `graff` stays the line REPL.**
  The pager takes the alt screen with a Grok-like composer (multiline wrap,
  Ctrl+Z undo, chips after the prompt), folded `◆ Called N tools` cards that
  click open to a thought-style preview, Shift+arrow jumps between user turns,
  and a searchable effort overlay next to the model picker. Markdown pipe
  tables render as box-drawing. Image paste/drop becomes `[Image #N]` chips
  with a metadata preview card. A headless `Term` driver lets tests type,
  click, and hover without a PTY.
- **First-run adopt copies Claude/Cursor MCP servers and skills.**
  `/import-claude` (and `graff mcp import`) writes into `~/.codegraff` and the
  current repo the same way Grok's import does. The first interactive start
  does this once; the command stays for a later rescan. Hooks are copied, not
  merged into `.harness/settings.json`.
- **Hosted tool lines stay inspectable.** Live `⚙ read path` / `✓ read | preview`
  rows carry the argument or a one-line result so the pager can harvest them
  into folded history without a raw JSON dump.
