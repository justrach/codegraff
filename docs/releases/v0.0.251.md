# v0.0.251 (2026-08-13)

A one-fix UX release on top of v0.0.250.

- **Peer messages get breathing room in the REPL.** Channel drains render at
  a step boundary, mid-stream, and the `[peer message from … — #469 channel]`
  lines butted straight against the assistant text above and whatever
  followed below — one clump. The visible block is now bracketed by a blank
  line on either side (including the debug-only presence/backlog markers
  when those are shown). History bytes are unchanged — this is render-only —
  and `session_notice` never reaches ACP, so the GUI is untouched.
